# 青叶科技网页小窗试衣扩展

这是青叶科技提供的无需构建 Chrome MV3 扩展。加载后，在普通 `http` 或 `https` 网页上点击图片，会打开一个 460×820 的独立小窗，并把图片带入本地青叶科技试衣页面。

## 安装

1. 打开 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录。
4. 确认本地页面已经运行在 `http://127.0.0.1:5173/`。

扩展只对点击的图片执行读取；需要读取图片所在站点的权限。需要登录或防盗链的图片可能无法被扩展读取，此时使用青叶科技试衣页面内的「上传衣服照片」。
